# Design System: Dr.Octopus Browser Extension

本文件维护当前视觉与交互契约，并在附录 A 登记每份视觉稿的实际状态。2026-11-03 按用户同意收敛过渡设计；此前逐次审阅、提示词和已替代图稿的原件见[历史归档清单](../../docs/design/browser-extension-recorder/history-manifest.md)。历史批准不自动变成当前整图批准。

产品范围见 [PRODUCT.md](PRODUCT.md)，录制契约见[录制架构](../../docs/architecture/browser-extension-recorder.md)，整理与重放见[统一 Skill Agent](../../docs/architecture/browser-skill-unified-agent.md)，存储见[浏览器优先保存](../../docs/architecture/browser-skill-offline.md)。运行验证只认 [PoC](../../docs/poc/executor-validation.md)，图稿不是运行截图。

## 视觉基础

- 延续黑白灰、紧凑仪器控件与细线图标；实心主按钮随浅深色反转，不增加装饰性渐变、插画或品牌色铺陈。
- 正常文字使用前景色；红色表达录制、错误与危险操作，绿色表达已整理、连接成功与成功反馈。warning/info Alert 使用既有语义 token，不用蓝黄颜色暗示普通运行或等待。配色不得成为状态唯一依据。
- 字体 Microsoft YaHei UI → Microsoft YaHei → system-ui；正文/标题 14px，辅助文字 12px，标题 600、正文 400。诊断用等宽字体，计时/计数用 tabular-nums；安装实例截断标识可用 11px。
- 圆角与颜色角色保留 frontmatter tokens；内部卡片无投影，浮于网页的录制浮条才使用 shadow-lg。Card 使用既有 size=sm 组合，不修改共享 shadcn 源组件。
- 提交用 default，次操作用 outline/ghost；录制入口为 MousePointerClick。可交互行保留 hover、active、focus-visible、pointer 与箭头；只读步骤不添加点击暗示。
- 标题栏/导航栏图标操作用原生 title 与 aria-label；截断数据可用 Tooltip。保留浅深色、键盘操作及 reduced-motion，状态变化有可访问反馈。

## 容器、导航与入口

Popup 宽 360px、高 600px，以 max-h-dvh 适配短屏；外层无 padding，html/body 不滚动。ExtensionPopup 只拥有品牌与「连接状态 / 录制重放」双 Tab，连接第一且默认选中。Popup 保留连接与录制管理；模型设置、整理/重放会话及其历史统一属于窗口级 window-panel 侧边栏。唯一设置入口位于 window-panel 品牌标题右侧；不再在 Popup 留设置页或整理历史页。

业务页面由 PopupPage 组合 NavigationBar、必要工具区、正文和 footer。固定区域不参与正文滚动。各区域通过应用级 Box 提供内边距，正文 Box 位于满宽 ScrollArea 内，滚动条在最右侧；Box 不默认加背景、圆角或边框。区块间距 16px、组内 12px、行内 8px。NavigationBar 的返回按钮、截断标题与右侧操作槽固定；返回保留来源筛选与滚动位置。

列表、导航和 footer 的分隔统一用独立 Separator，不使用 divide-* 或行上的 border-t/bottom 模拟。列表具有独立 gap-0 容器、外层 py-2、Separator my-2；行内 p-2、最小高度 48px，长文本可自然增高，日期标题/字段间距保留，不在每个字段重复嵌套 Box。

普通正文只有一个共享 ScrollArea。会话将 MessageScrollerViewport 与 ScrollArea Viewport 合为同一 DOM，保留锚定与回到最新；例外仅为下文明确允许的展开 JSON 卡片。侧边栏沿用固定品牌/导航/footer，自适应可变宽高，不复制连接/录制 Tab，也不增加第二列常驻侧栏。

## 连接页与录制

连接 Tab 带 6px 状态圆点：connected 绿色，disconnected/incompatible 红色，connecting/paused/未取得状态灰色；由实时 Worker 状态驱动，不增轮询、不信任旧 storage 状态。圆点有可访问名称，Tab 的 title 说明状态。

连接 footer 固定沉底，版本/安装实例采用 label/value 左右布局。安装实例前 8…后 4 截断、Tooltip 显示全值；复制成功后才显示绿色对勾，约 1.5 秒还原，重复点击重置计时。失败显示可访问反馈。连接页采用 [最近一次连接方案 1](../../docs/design/browser-extension-recorder/connection-status-summary-v1.png)：实时连接状态与工具链仍优先，最近一次成功握手时间作为轻量记录，历史异常仅在折叠的连接诊断内显示；从未成功连接时明确显示尚无连接记录。心跳不得改写最近一次连接时间，历史异常不得冒充当前状态。

录制浮条使用 Paper/Fog、圆角及 shadow-lg，包含拖动、品牌、状态、计时、步骤/页面数、暂停/继续、停止保存与收起。收起不暂停，暂停说明期间操作不会记录。位置限制在可视区内，拖动不触发业务操作；图标有可访问名称与 Tooltip，错误使用 role=alert。

录制首页最近 5 条，全部列表每批 20 条游标、全存储搜索、手动加载更多；详情每批 50 条原始事件。返回保留查询与实际 viewport 位置，旧请求不覆盖新结果。Empty、Skeleton 与失败重试分别呈现；已加载数量不冒充总数。列表状态为待整理 / 整理中 / 已整理，已整理不表示重放成功。

录制详情从未整理时显示「开始整理」；已有整理时显示「查看整理」（FileText），打开最新创建的整理会话，不因旧会话未完成而覆盖最新记录。重放明确新建任务，存在活跃重放时显示「查看重放」并说明不会新建。重新整理由完成会话底栏显式发起，创建副本，不能覆盖手改技能。删除录制保留原确认，不顺带删除磁盘技能。

## 技能保存与离线反馈

默认浏览器事务保存成功即显示「已保存到浏览器」；确认 Native 回执后显示「已关联本地目录」。Executor 离线不阻止默认整理与重放，但仍需模型及目标网站网络。文件区复用 Button/DropdownMenu 提供导出副本、保存到本地目录、打开关联目录；无关联不能显示可打开磁盘。

关联磁盘的技能优先读当前文件；仅连接不可用时通过 Dialog 确认使用绑定摘要的浏览器副本，提示副本时间及可能遗漏手改。未确认不创建运行；格式/权限/缺失错误不静默降级。会话仅在缓存降级时提示来源。浏览器保存失败提供重试保存，不重新调用模型；磁盘写入失败不撤销浏览器成功结果。完整边界只维护在离线架构。

## 会话与问答

window-panel 首页是会话历史，用全部/整理/重放 Tabs 筛选；列表/详情两级导航，标题栏历史入口返回列表。条目包含类型、录制名称、状态、最近活动时间。按显式 ID 查看，保留筛选、已加载条数和滚动，不被后台新任务替换；看其他会话不卸载当前模型宿主，并可返回运行/待答/待核实会话。关闭面板保留会话，重新打开显式继续。

时间线顺序呈现真实任务活动、工具调用/结果、当前问题、只读答案和结果，不补造思考。节点 20px、图标 12px，节点与标题首行居中；节点间细线连续，末节点后不延伸，问题位于对应工具节点。整理不能显示正在操作网页，重放可显示实际页面工具活动。

Questionnaire Root 是唯一 form，字段由 TanStack Form 管理；支持单选、多选、文本、邮箱、数字、日期，一次 ask 最多 4 个相关字段且只有一个待答调用，不显示虚构全局进度。标题/字段 14px，输入及日期触发器 32px，选项最小 32px、长文案可增高，字段组间距 16px。日期用 Button + Popover + Calendar，中文、YYYY-MM-DD，不经 UTC 转换；选择后恢复焦点，可清除，Portal 不被正文裁切。

选择题提供「其他，自行说明」，其他字段可切「不适用／自行说明」，在原 QuestionnaireItem 内展开 QuestionnaireInput，说明非空；切回普通模式按原校验。不新增自由聊天、独立 Textarea 或全局发送框，不自动把说明当参数字面值。

提交先事务保存答案，ACK 后才只读/继续；失败保留输入并就地报错，重试不能重复答案或创建两个 Host。「稍后处理」保留待答，只有问题允许才有「暂不提供」；历史答案不能直接回改。上翻不强制滚底，有新内容提供回到最新；流式消息不抢输入焦点，同会话重开定位待答。

停止任务保留导航位置，使用红色实心按钮及填充方块图标，忙碌禁用；停止不承诺撤回已派发动作。失败统一显示「失败」及 destructive 图标，重放 completed 显示「已结束」，不冒充业务成功。中断按可恢复性继续；未知结果阻止后续副作用，人工核实后继续，不能盲目重试原动作。

工具 JSON 使用现有 Card 与原生 details/summary，ChevronRight 表示展开，隐藏原生三角。JSON 视口最多 min(20rem, 40dvh)，短内容自然高度，使用共享 ScrollArea，溢出可聚焦/键盘滚动，边界衔接会话；问题与错误操作区不裁切。此局部规格已于 2026-11-03 获直接批准，非已弃用整套卡片设计的恢复。

仅当前实际执行节点显示 motion-safe 动效；待答、失败、完成、中断、停止与保存错误静态。页面等待在当前打开/导航节点内显示「等待页面就绪… 1/3」或「页面尚未就绪，重试中… 2/3」，分母取任务配置、次数来自 Worker，折叠仍可见；结束隐藏。使用中性色、role=status、reduced-motion，200% 放大可换行，不新增警告卡或模型消息。

## 设置与错误恢复

设置统一 TanStack Form + Field，一次「保存配置」提交模型、密钥更换、发送授权与执行限制；测试连接是独立操作且不保存配置。密钥只显示保存状态与更换/清除，不回填明文。模型拉取与测试离开设置/配置改变时取消，反馈为原页顶部 Alert toast，不挤动表单、不创建整理任务。

整理入口仅检查配置与 endpoint 授权，不预先测试连接；首次发送经明确确认，后台重新核对。配置修复保留录制上下文；限流、临时不可用与输出校验错误留在会话，不强制跳设置、不自动重试，不恢复旧录制通用修复入口。

跨窗口干净表单自动同步；有草稿时保留编辑，以 warning Alert 提供「加载最新配置 / 保留当前编辑」，冲突未处理禁用保存。设置往返保留会话与表单。

执行轮数：整理默认 50、重放 100，范围 1–500。耗尽显示已用/上限、设置入口和「追加轮数并继续」，确认最多追加 20，总上限 500。页面等待在执行限制后分组，1–60 秒、连续 1–5 次，默认 15/3；仅影响新任务，等待不重复打开页面或额外请求模型，仍由统一保存按钮提交。

会话、工具与校验错误 Alert 的 action 区默认显示「复制诊断」（Copy、outline、xs）。仅复制有限 ID、模式/状态、epoch/revision、时间、调用数、错误码/安全说明、工具位置和白名单字段路径；不复制接口地址、密钥、名称、模型正文、用户输入或工具原始数据。剪贴板完成后才显示已复制，失败可重试，切换诊断清旧反馈。

纯文本回复保留在时间线，只有 submit_skill 回执或 finish_run 结果才能终结任务。空输出、截断、过滤、未知结束与纠正上限分别报错；旧 SKILL_NO_TOOL 可显式继续，不跳过未知副作用核实。ask_user_question 参数错误只有后续问题正式接纳或真实 answered 回执才标为「参数已纠正」，默认折叠 info Alert，原始安全诊断保留；其他失败仍为 danger。诊断优先读同 toolCallId/toolName 的持久账本，不猜测旧数据缺失字段。

## 删除会话

状态 Badge 后紧邻 destructive icon-xs 删除按钮，title/aria-label 为删除会话。Dialog 中取消左、确认右；提交绑定原 revision/epoch，状态变化要求重试。执行/保存中及未知副作用禁止删除，禁用原因可见；静止待答可删除，成功回会话历史并清理详情导航。

默认仅删会话和问答。整理有生成产物时提供默认未选中的「同时删除本次生成的技能」，清理该生成 ID 的浏览器副本及本地文件，明确包含本地手改及连接要求；保留录制和后续生成。失败留在 Dialog 并保留选项与会话；重放没有此选项。具体跨存储失败语义见统一 Agent 架构。本规则已于 2026-11-03 获直接批准。

## 视觉验收与文案弹性

视觉验收看配色、布局、层级、组件与交互结构。除明确固定文案外可按实际功能优化文字；仅文案变化无需重出稿，但必须验证换行与可读性。权限、隐私、保存、删除和完成状态必须准确，不借文案改变行为。重大视觉改动仍先出稿审阅；实施授权与运行验收独立记录。
