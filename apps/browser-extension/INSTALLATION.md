## 连接条件

先启动 Executor、启用桥接、创建 browser 能力授权并复制 MCP 配置。Host 与实际数据目录按配套 Executor 的安装说明处理。组件配置、实时握手、工具就绪和客户端授权分别核对。

网站访问权限在插件详情管理。受保护/隐身、权限不足、冻结/丢弃页面可被拒绝；重连不自动刷新、解冻或恢复旧动作。

## 弹窗

当前工作区构建的弹窗首先展示「连接」，录制为独立 Tab；已有安装包是否包含录制功能，以其实际产物为准。

- 显示浏览器、版本、安装实例、当前连接与工具就绪，只依据实时 Worker 握手。
- 未连接可重新连接，已连接可刷新状态。
- 暂停断开并保存偏好，重开/Worker 重启不会自行恢复，需明确恢复连接。
- 已派发动作可能继续或未知，不自动重放；关闭弹窗只释放自身监听/计时器，后台继续。
- 支持系统浅深色和 reduced-motion。
- “最近一次连接异常”保留时间、错误码、当时可确认的工具名及分类后的 Native Host 原因，自动重连和 Worker 重启不会清空。它是历史记录，不代表当前仍断开；不会记录网页内容、URL、请求参数、原始系统错误或凭据。

弹窗不能启动 Runtime、读取 Bearer、执行网页动作或绕过授权；工具由智能体通过 Executor 有限 MCP 调用。

## 录制与记录查看（包含录制功能的构建）

1. 打开要操作的普通网页，在扩展的「录制」Tab 确认起始页面；需要跨页流程时，可选择包含同一窗口、已允许站点的关联新页面。
2. 点击「开始录制」，用网页浮条暂停、继续或停止保存。关闭弹窗不停止录制；输入原值不写入记录，范围外页面不会自动纳入。
3. 首页显示最近 5 条记录。点击「查看全部」可搜索全部本地记录，列表按每批 20 条「加载更多」，进入详情后返回会保留筛选和浏览位置。
4. 详情按每批 50 条事件加载，可重命名或经确认删除。部分保存记录会显示缺口说明，不代表完整流程已成功。

权限撤回或参与页被冻结/丢弃时，该页会退出录制范围；恢复可用后不会自动重新加入。保存遇到本地存储错误时，先处理存储问题，再尝试停止保存；未确认的操作会标记为可能缺失。浏览器重启后不会自动续录。

暂停 Executor 连接与暂停录制是不同操作。遇到浏览器自动化正在使用页面的提示，先结束对应任务再录制；不强行抢占。当前开发构建可在录制详情整理为本地技能并重放。

## 检查连接

在弹窗核对实际版本和当前连接，再通过 MCP 客户端执行一次已授权的浏览器工具。只看到“已连接”不能证明客户端已获得 browser 授权或目标网站权限。

分别测试 Chrome/Edge、暂停和恢复；更新配套 Executor 或插件后重新检查连接。企业策略可能禁止开发者模式或 Native Messaging，按实际错误排查，不以本地目录加载成功判断所有环境可用。

定位“调用后掉线但弹窗又显示已连接”时，查看最近一次连接异常：`invalid_message` 表示 Worker 拒绝 Host 消息格式，`invalid_request` 表示连接身份、重复请求或并发限制不符合契约；`disconnected` 配合 `host_exited` 表示 Native Host 已退出，需要进一步检查 Host 端原因，不能仅凭此认定协议不兼容。更新扩展后核对弹窗版本；旧页面的内容脚本也可能需要刷新页面才能替换，但不要刷新仍有未确认操作的页面或重放旧动作。

## 原生页面反馈

0.1.5 使用 PageController 原生彩屏、箭头与默认高亮。第一次页面快照后，在同一任务的观察、思考和动作间持续显示；结束任务、暂停连接或断开后清理。DOM 快照和元素索引交给上游，不再用自建 DOM 监听让任意页面变化使整份快照失效。此版本的桥接协议为 4，需要配套更新并重启 Executor，再重新加载扩展；旧版本会明确显示版本不兼容。

## 整理技能与重放（开发验证中的构建）

1. 弹窗保留「连接状态」「录制重放」两个 Tab，默认展示连接状态。智能体侧边栏品牌标题右侧的设置按钮打开模型配置；接口地址支持 HTTP/HTTPS，模型可手填或拉取搜索。保存配置会保存本次输入的 API Key，按接口绑定，仅保存在此浏览器、不同步；再次进入显示已保存，可更换或清除，不回填密钥明文。本机存储不等同于系统密钥库加密。
2. 「测试连接」仅发送短模型请求，可能计费；结果在原页顶部显示，不开始整理，也不自动保存。修改配置或离开设置会取消测试。
3. 打开一份录制，首次点击「开始整理」；已有未完成任务显示「继续整理」，已完成显示「查看整理」，均打开对应会话。需要重新生成时，在已完成会话中点击「重新整理」。智能体分析脱敏事实，必要时提出有界问题；选择或填写后点击「确认并继续」。没有自由聊天框。「稍后处理」保留待答任务；只有显式「暂不提供」才把该决定交给智能体。关闭弹窗不删除会话，未提交输入不承诺跨关闭保存。
4. 技能生成后默认保存到此浏览器，整理完成即可重放，不需要连接 Executor。浏览器存储失败时保留候选，点击“重试保存”不会重新调用模型。
5. “导出技能”下载包含 `SKILL.md` 和 `workflow.json` 的 ZIP。连接 Executor 后，可在“技能文件操作”菜单选择“保存到本地目录”，写入 `~/.dr-octopus/executor/skills/browser-recordings/<安装实例>/<技能ID>/`。只有回执确认后才显示“查看 SKILLS”；断线可重试同一份副本，不覆盖已有文件。清除浏览器数据或卸载扩展会丢失浏览器副本，请按需导出或保存到本地目录。
6. 点击“重放”，确认向模型发送本次技能、输入和必要页面观察。默认浏览器技能直接使用已保存内容；已关联本地目录的技能先读取当前磁盘文件，手工修改影响下一次运行。Executor 不可用时可明确选择使用浏览器缓存，界面显示副本时间并提示可能未包含后续修改；本地文件缺失、损坏或越权不会自动改用缓存。重新整理生成新浏览器副本，不覆盖旧磁盘文件。离线表示不连接 Executor，模型服务和目标网页仍需可用。
7. 会话显示工具调用、回答与结果。运行中可停止，但不能撤回已派发的页面动作。发生未知结果时停止后续操作；请检查实际页面，再通过「核实并结束任务」确认结束。系统确认页面已空闲后解除占用，不自动重复点击或发送。
8. 智能体侧边栏的会话历史按任务查看整理或重放过程，保留失败诊断；不再展示旧工作流历史。删除录制仍需确认，不连带删除本地技能。

模型请求上限由下文的「执行限制」设置决定，均不自动重试。模型声明完成不等于独立验证业务成功；重放「已结束」需结合结果摘要和实际页面判断。保留当前录制、新版技能会话及本地技能；旧工作流测试数据和已导入历史摘要在更新时删除，不再提供兼容展示，原编辑/发布入口已移除。

重放遇到页面不可访问时，会区分站点范围、任务窗口、隐私页面、页面类型及浏览器权限问题。权限不足时，智能体只能询问你如何处理或报告未完成；在浏览器中恢复站点权限后回答问题，扩展会再次检查实际权限并重新观察。回答“已恢复”不会直接授予权限。错误卡片的“复制诊断”包含具体拒绝原因和可选 tabId/origin，不包含完整页面路径或查询参数；旧会话未记录的原因不会被补造。

在智能体侧边栏右上角设置 →「页面等待」中，可配置每次等待时长（1–60秒，默认15秒）及连续超时次数（1–5次，默认3次），与模型设置一起点击底部「保存配置」。保存仅影响新建任务，任务创建时固定等待策略。打开/导航后在同一页面连续等待，任一次就绪即继续；达到连续超时次数才以PAGE_READY_TIMEOUT结束本次任务，保留已打开标签页。等待过程不产生额外模型请求、不重新打开页面。权限拒绝、标签页关闭等明确错误不按慢加载重复等待；SDK及后台超时会随等待预算自动协调。

开发验证使用隔离环境与合成模型。真实模型质量、物理输入与正式商店安装仍须分别验收；更新扩展及配套 Executor 后再测试，不在日常业务页直接试跑未核对技能。

技能名称支持中文、英文及混合名称；文件仍保存到独立技能ID目录。元信息缺失、格式或参数引用出错时，“查看校验详情”会显示具体原因与修正提示。更新后的规则不会修改历史失败记录，需由你明确点击“重试整理”启动新任务。

### 智能体执行限制

点击智能体侧边栏标题右侧设置按钮，在“执行限制”中配置整理最大轮数（默认 50）和重放最大轮数（默认 100），范围均为 1–500。每轮是一次模型请求，不等于一个页面操作。执行限制与模型配置一起通过页面底部“保存配置”提交，保存仅影响新任务。提高上限可能增加模型费用。

任务达到上限后，详情显示已用轮数，可点击“追加轮数并继续”并确认追加 20 轮（总上限 500）。继续保留原会话与已完成操作；重放先重新观察页面。不会自动追加或重新执行已完成操作，存在未决操作时不能通过追加绕过核实。

### 智能体侧边栏

工具栏图标仍打开原弹窗。连接状态、录制列表/详情和技能文件保留在弹窗；点击开始整理、查看整理或重放，会打开当前窗口的智能体侧边栏。整理和重放不再新建Agent运行标签页，重放仍在真实业务网页执行。

切换网页、关闭弹窗不影响侧边栏会话。关闭侧边栏会停止后续执行并保存进度；重新打开后点击“继续”，待答问题仍需提交答案。已经派发的页面操作无法撤回，结果未知时需核实后处理。侧边栏可调整宽度，原时间线、提问和底部操作保持。当前窗口重放不会操作其他窗口中的网页；另一个窗口可以查看会话，但不能接管仍打开的原窗口任务。

### 会话历史

侧边栏首页统一展示整理和重放会话，按最近活动排序，可筛选全部、整理、重放并加载更多。点击条目只查看，不自动调用模型；运行中查看历史不会中断任务，可通过“返回进行中会话”回到当前任务。返回列表后关闭并重开侧边栏仍进入列表；关闭于详情时重开原详情。

录制详情的“查看整理”打开该录制最新创建的整理会话，包括失败或待回答的记录；从未整理时显示“开始整理”。“重放”创建新会话；已有进行中、待回答或待核实重放时显示“查看重放”，避免重复执行。重新整理从整理会话详情发起。

整理和重放会话详情右上角可删除会话，默认只删除会话及问答记录，保留录制与已生成技能。整理会话有生成产物时，可勾选「同时删除本次生成的技能」，统一删除浏览器副本及已保存到 Executor 的对应技能文件（含手工修改）；不会删除其他整理会话生成的技能。仅浏览器保存可离线删除；曾尝试保存本地的技能需连接 Executor 确认清理。删除失败保留会话和浏览器副本，可重试；本地操作可能已部分完成。含额外文件或链接的目录需自行处理，不递归清理。重放会话不提供此选项。执行中、结果待核实或技能仍被未结束的重放使用时需先停止/核实。

### 自行说明与设置同步

单选、多选问题可选择“其他，自行说明”；日期、数字、邮箱、文本字段可点击“不适用／自行说明”。填写具体原因，例如“不需要有效时间，请移除此参数”，再确认提交。选择自行说明后无需填写该字段原来的值；其他字段仍需按要求回答。“稍后处理”仍保留问题，不代表不需要该参数。已存在的待答问题同样支持该入口。

模型配置、发送授权和执行限制统一在window-panel右上角设置中编辑，Popup不再显示设置入口。多个窗口同时打开设置时，未修改的表单同步最新保存值；有未保存编辑时提示冲突，可加载最新配置或保留当前编辑再保存。设置变化仅影响后续新任务，不自动重启会话；已保存密钥不会显示明文。

设置页只有一个“保存配置”按钮，一次保存模型、API Key更换、发送授权及整理/重放最大轮数。任一字段不合法则不提交；保存失败保留当前输入。测试连接不保存任何字段。跨窗口冲突按整份配置处理，不再单独保存执行限制。

### 模型只返回说明时

整理和重放会保存本轮回复及结束原因。若模型只返回文字而未调用工具，会在原任务预算内尝试纠正，每个会话最多增加2次模型请求；重放纠正仅允许读取、观察、提问或报告结果，不重新点击、填写或提交。真实用户回答后才恢复常规执行。空输出、截断、内容过滤等会给出独立错误，复制诊断包含响应摘要。

更新前因SKILL_NO_TOOL失败的会话，可在详情明确点击“继续整理”或“核对并继续”；重放先观察当前页面。旧版本未保存的最后一轮回复无法补回。不要将订单已创建或待支付视为支付成功。

## 录制选择与重放确认

单选、复选和下拉选择会作为技能中的明确要求保存，不再把旁边的日期、价格说明当作填写参数。重放会按要求应用选择并核对实际状态；缺失、重名或不可用时会询问，不自动改选其他项。

改变或删除选择要求需要单独确认。“不需要填写日期”等普通回答不会顺带删除其他选择。重放中的确认只对本次运行生效，不改写技能文件；后续运行仍从保存的技能开始。

更新后请重新加载扩展。旧录制如果缺少控件类型或选择状态，会提示重新录制；不会猜测补齐，也不会覆盖已有技能。使用本地技能目录时，请同时更新配套 Executor。

当前不自动修改原生多选下拉，无法可靠处理的自定义控件会转为询问。同一控件跨操作阶段使用不同选择时，请分段录制。为避免未满足要求就提交，普通点击受到保守保护；普通输入可直接填写，需要先展开页面的复杂流程可能需要你协助。
