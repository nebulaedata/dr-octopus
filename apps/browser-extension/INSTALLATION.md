## 加载与更新

取得对应 Chrome/Edge 的完整扩展目录；独立 ZIP 先完整解压到稳定目录，验收包从 Executor 连接页打开对应目录。所选目录根部应包含 manifest.json。

1. 扩展管理页启用开发者模式，加载完整已解压目录。
2. 保留该目录及许可证，不混入旧文件；更新后重新加载新目录，旧包不会自动更新。
3. 在扩展菜单固定 Octopus Browser Bridge：Chrome 图钉、Edge“在工具栏中显示”；扩展不自动修改固定状态。

## 连接条件

先启动 Executor、启用桥接、创建 browser 能力授权并复制 MCP 配置。Host 与实际数据目录按配套 Executor 的安装说明处理。组件配置、实时握手、工具就绪和客户端授权分别核对。

网站访问权限在插件详情管理。受保护/隐身、权限不足、冻结/丢弃页面可被拒绝；重连不自动刷新、解冻或恢复旧动作。

## 弹窗

- 显示浏览器、版本、安装实例、当前连接与工具就绪，只依据实时 Worker 握手。
- 未连接可重新连接，已连接可刷新状态。
- 暂停断开并保存偏好，重开/Worker 重启不会自行恢复，需明确恢复连接。
- 已派发动作可能继续或未知，不自动重放；关闭弹窗只释放自身监听/计时器，后台继续。
- 支持系统浅深色和 reduced-motion。
- “最近一次连接异常”保留时间、错误码、当时可确认的工具名及分类后的 Native Host 原因，自动重连和 Worker 重启不会清空。它是历史记录，不代表当前仍断开；不会记录网页内容、URL、请求参数、原始系统错误或凭据。

弹窗不能启动 Runtime、读取 Bearer、执行网页动作或绕过授权；工具由智能体通过 Executor 有限 MCP 调用。

## 检查连接

在弹窗核对实际版本和当前连接，再通过 MCP 客户端执行一次已授权的浏览器工具。只看到“已连接”不能证明客户端已获得 browser 授权或目标网站权限。

分别测试 Chrome/Edge、暂停和恢复；更新配套 Executor 或插件后重新检查连接。企业策略可能禁止开发者模式或 Native Messaging，按实际错误排查，不以本地目录加载成功判断所有环境可用。

定位“调用后掉线但弹窗又显示已连接”时，查看最近一次连接异常：`invalid_message` 表示 Worker 拒绝 Host 消息格式，`invalid_request` 表示连接身份、重复请求或并发限制不符合契约；`disconnected` 配合 `host_exited` 表示 Native Host 已退出，需要进一步检查 Host 端原因，不能仅凭此认定协议不兼容。更新扩展后核对弹窗版本；旧页面的内容脚本也可能需要刷新页面才能替换，但不要刷新仍有未确认操作的页面或重放旧动作。

## 原生页面反馈

0.1.5 使用 PageController 原生彩屏、箭头与默认高亮。第一次页面快照后，在同一任务的观察、思考和动作间持续显示；结束任务、暂停连接或断开后清理。DOM 快照和元素索引交给上游，不再用自建 DOM 监听让任意页面变化使整份快照失效。此版本的桥接协议为 3，需要配套更新并重启 Executor，再重新加载扩展；旧版本会明确显示版本不兼容。
