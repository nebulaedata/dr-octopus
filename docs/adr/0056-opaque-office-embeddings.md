# ADR-0056：Office 嵌入部件保留为不透明数据

- 状态：Accepted
- 日期：2026-09-16
- 范围：DOCX、PPTX、XLSX 的预检、共享 Office 解析器与覆盖诊断

## 背景

原策略在发现普通嵌入附件时拒绝整个文档，导致可读取的外层正文也无法使用。
覆盖诊断已有 EMBEDDED_CONTENT，但普通嵌入部件无法经过准入和解析到达诊断阶段。

## 决策

- 使用共享 `classifyOfficePart` 分类规则，供 Server 预检、Office 解析器及覆盖收集器使用。
- 标准 `word/embeddings/`、`ppt/embeddings/`、`xl/embeddings/` 内的文件可作为不透明部件保留。
  允许的含义是继续读取外层文档，不是批准执行或认定嵌入文件内容安全。
- 嵌入部件仍参与外层 ZIP 大小、解压预算及 CRC 完整性验证；不递归解包，不执行，
  不解析其内部文本，即使部件后缀是 XML 或 rels。
- 外层宏、ActiveX 和嵌入目录外的不支持二进制部件仍拒绝；非普通超链接的外部关系仍拒绝。
  PDF 的嵌入对象准入规则不变。
- 外层 oleObject/package 关系必须指向存在的标准嵌入部件；其他外层解析路径也不能将嵌入部件当作 XML 消费。
- 覆盖结果记录 `EMBEDDED_CONTENT / not-processed`、部件数量及真实包内路径。
  正文继续提取；不新增精确段落或幻灯片定位，也不单独物化嵌入文件。
- Word Equation.3 的现有文本占位提示保留；它不再是允许不透明嵌入部件的唯一例外。

## 影响与边界

共享 Office 解析器的使用者均获得该行为，不修改 Agent 核心，不新增模型调用或依赖。
原件、提取结果和覆盖信息继续走现有工作区交付流程，由智能体按任务决定后续处理。
嵌入文件内部是否含有宏等内容不在本次检查范围，因为内部文件没有被打开或解释。

## 验证

- 三种 Office 格式的预检与覆盖诊断接受普通嵌入部件，正文不混入嵌入字节。
- 嵌入关系缺失目标、指向外层正文、路径越界或通过 worksheet 关系尝试读取嵌入 XML，均拒绝。
- 宏、ActiveX、外部关系及 ZIP CRC 损坏继续拒绝。
- 真实附件处理子进程、处理摘要、持久化投影和智能体提示保留嵌入内容未覆盖信息。
