# ADR-0062: 固定父工作区边界并在子入口统一复核启动权限

## Status

Accepted

## Context

ADR-0061 存在两处遗漏：子 cwd 改变会把父工作区外目标重新判定为内部路径；/run 与第三方结构化委派不经过父 tool_call，因此可能对新任务复用旧权限。pi-subagents 的公开 required-child-extensions API 只提供固定入口，没有统一的动态启动回调。

## Decision

- 权限快照升级到 version=2，固定父 cwd。实际参数仍按子 cwd 解析，但外部路径判定使用父边界。交互权限调用默认继续使用自己的 cwd，保持既有行为。不新增文件系统沙箱。
- 每个桥接实例持有一个仅监听 127.0.0.1 的启动复核端点，使用随机能力令牌。所有生成的子入口在注册工具前异步复核其快照摘要，覆盖前台、后台、/run、第三方 API 和后代入口。接口不能执行工具或修改权限。
- 父端重新捕获模式、配置、活动工具、集合与会话身份，并刷新上游注册入口。旧摘要不匹配时拒绝当前启动，返回 CHILD_SCOPE_STALE；调用者重新委派即可获取最新入口。不能以新权限静默升级旧入口，尤其不能扩大后代继承权限。
- 不使用第三方私有注册表，不修改第三方包。已经完成准入的子会话保留固定快照，不在每次工具调用时访问父端。
- 父会话关闭后端点关闭，已启动任务继续运行；尚未准入的任务或新的后代不能离线绕过验证，返回 CHILD_ADMISSION_UNAVAILABLE。重启父会话后须重新委派。
- 入口文件包含权限快照与短期本机启动能力令牌，以现有私有目录及 0600 文件发布。不包含模型凭证。父关闭即失效，不将令牌写入诊断或日志。旧 version=1 快照不再执行。

## Consequences

通过拒绝过期启动修复权限扩大；/run 或 API 在权限变化后的首次尝试可能收到明确过期错误，需要重试，而非透明扩大原委派权限。正常启动增加一次本机请求；父失联、超时或配置错误时拒绝启动。后台运行不需要持续连接父端。

测试覆盖父外部绝对/相对路径、子目录切换、绕过父 tool_call 的模式变化与活动工具变化、错误令牌、父关闭，以及真实 Pi 前后台子会话。
