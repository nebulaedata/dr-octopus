# ADR-0069：可选 Jev 判断能力

## 决策

系统设置的 Jev 页面仅配置模型和 API Key，密钥在前、模型在后，不设置通用启用开关和刷新按钮。自动记忆前置判断在记忆设置中独立配置，默认关闭；不建立通用流程编排框架。

- Agent 的 `lib/jev` 持有官方 `@typesafe-ai/sdk` 的 Choice 适配和 `agentDir/jev.json` 配置读写。CLI 与 Web 使用同一配置目录，Server 只提供管理入口。非秘密配置写入复用 OS 锁、修订校验和原子替换。API Key 仅使用 `TYPESAFE_API_KEY`，Jev 页面直接编辑并复用已有环境存储写入 `agentDir/environment.json`；新 Agent 将其加载到环境变量。`jev.json` 不保存密钥，API 仅返回配置状态、覆盖状态及修订号。密钥与模型分别保存并校验各自修订，防止两个文件部分成功被误报为整体成功；启动环境优先，页面明确提示覆盖关系。
- 记忆模块持有筛选提示词、启用开关、超时和 skip 阈值，持久化到全局记忆目录下的 `screening.json`，通过 `/api/memory/screening` 管理。Jev 的 `jev.json` 只保存模型；二者独立修订，评估期间任一配置改变均丢弃结果。只有成功回合、auto 模式且满足现有写入权限时才能筛选；显式保存绕过 Jev。提示词全英文，用户证据保留原文。
- 当前只发送本轮选出的用户证据，不传入助手思考、工具输出、API Key 或完整会话。可能依赖缺失上下文的结果应继续整理。
- 只有有效结果选择 skip，且 skip 概率达到配置阈值时才跳过。阈值默认 0.95，下限 0.95；它是保守工程策略，不是经过生产校准的漏记保证。
- 默认模型固定 `jev-1.13.0`，记忆前置判断默认超时 1500 ms。SDK 显式关闭自动重试和日志，使用配置超时与调用方取消信号；请求不跟随重定向；异常、超时、无效结果或评估期间配置改变均继续原整理。调用方取消仍必须传播，不能当成故障降级后继续写入。
- 非秘密配置每次评估读取，无需重启；密钥沿用环境变量生效规则，新启动的 Agent 加载变更，已有进程需重启。关闭时不调用 Jev；连接测试由用户显式触发，使用固定合成文本，不改变开关或记忆。
- 页面说明启用会向 TypeSafe 发送用户文本；已有桌面测试密钥不自动导入产品配置。未来节点复用客户端并自主管理自身提示词、启用条件和结果策略。

## 验证

覆盖默认关闭零网络、环境凭据优先级、不写入 Jev 文件及不回传、并发修订冲突、概率边界、格式异常、模型版本、超时、取消、配置中途改变，以及显式保存/手动模式/关闭模式不调用 Jev。设置页同时覆盖独立页面与弹窗入口；原有记忆回归继续执行。

官方模型与 SDK 依据：[模型列表](https://docs.typesafe.ai/models)、[JavaScript SDK](https://docs.typesafe.ai/sdk/javascript)。保存 API Key 后，页面通过服务端调用官方 SDK `models.list()` 自动加载下拉选项。官方列表可能仅返回别名，因此保留当前配置的模型；请求失败不改变已选模型，并提供重试。
