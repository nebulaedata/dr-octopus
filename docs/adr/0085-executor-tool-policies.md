# ADR-0085：Executor 工具启用策略

- 状态：Implemented
- 日期：2026-10-21
- 修订：2026-11-02，统一为保存后完整重启生效，替代动态发布与重新应用流程。

## 背景

客户端授权描述可使用的能力，Executor 还需要统一的逐工具开关。用户应能从只读开始，在不重新授权的情况下配置工具集合；策略不承担路径、参数或审批规则。

## 决定

- 在 Executor settings.json 保存选中策略、自定义策略和递增修订号。内置只读与全部不可修改，自定义策略使用稳定 UUID 和有限工具名称白名单。只读允许观察、搜索和任务管理，禁止文件写入、Shell、网页交互及桌面输入。
- 工具分类和只读定义归 Runtime 的工具策略模块，有限配置 Schema 归 contracts。清单与真实注册目录的一致性由回归测试验证，新增工具须明确选择只读分类。
- MCP 发现过滤策略、授权与可用性；每次工具调用在任务或副作用产生前再次检查当前策略，禁用返回 TOOL_DISABLED。客户端缓存清单不能绕过此检查。
- 保存策略不改变当前 Runtime 的工具集合；包括收紧权限在内的工具集合变更，完整重启执行器后生效。重启沿用既有连接断开和任务停止流程；保存本身不取消在途操作，不改变内部清理、本机 Esc 与已签发文件传输 URL 的生命周期。
- Main 使用已有设置写入锁和设置发布日志持久化策略，拒绝过期草稿。启动时向 Runtime 传入已保存的工具集合与修订号，TaskAuthority 在构造时固定该集合，不提供运行中修改接口。实际启用的工具集合与启动值不同时，纳入已有 pendingRestart 判断和完整重启入口；仅名称、工具顺序或未选中策略变化不要求重启。恢复原工具集合后消除策略引起的待重启状态，其他设置的待重启状态继续保留。
- 设置主页面仅保留策略选择器和编辑入口。自定义编辑使用分类导航、搜索、逐项勾选和当前筛选全选，弹窗“确认”仅更新页面草稿。选择、编辑、复制与删除统一参与设置页 diff 检测、撤销和“保存设置”；只有显式保存才通过同一设置 IPC 与同一次发布写盘，完整重启后生效。生效提示由统一的立即生效／重启生效映射生成；工具概览使用启动时的策略快照，不能把已保存配置当成当前权限。窄窗口分类改用下拉。系统策略可复制，复制/删除收于更多菜单，关闭脏草稿需明确放弃。

## 影响与验证

策略沿用现有配置持久化与重启生效流程，独立于现有授权、Browser 桥接开关和 Computer 防护，不改变 Agent core。测试覆盖持久化、无效/过期请求、受信 IPC、统一待重启判断、重启前后的 MCP 发现与调用权限，以及真实 Electron 的新建、搜索、复制、删除、放弃与重启恢复。此前的动态应用测试属于旧行为，现由重启生效回归替代。构建与实际视觉证据记录于 Executor 验证状态，发行与独立硬件验收保持各自门禁。
