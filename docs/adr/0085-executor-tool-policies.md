# ADR-0085：Executor 工具启用策略

- 状态：Implemented
- 日期：2026-10-21

## 背景

客户端授权描述可使用的能力，Executor 还需要统一的逐工具开关。用户应能从只读开始，在不重新授权、不重启服务的情况下切换工具集合；策略不承担路径、参数或审批规则。

## 决定

- 在 Executor settings.json 保存选中策略、自定义策略和递增修订号。内置只读与全部不可修改，自定义策略使用稳定 UUID 和有限工具名称白名单。只读允许观察、搜索和任务管理，禁止文件写入、Shell、网页交互及桌面输入。
- 工具分类和只读定义归 Runtime 的工具策略模块，有限配置 Schema 归 contracts。清单与真实注册目录的一致性由回归测试验证，新增工具须明确选择只读分类。
- MCP 发现过滤策略、授权与可用性；每次工具调用在任务或副作用产生前再次检查当前策略，禁用返回 TOOL_DISABLED。客户端缓存清单不能绕过此检查。
- 策略只影响新的 MCP 调用。已经开始的操作、内部清理、本机 Esc 与已签发文件传输 URL 不被取消，继续使用原来的授权、期限和任务生命周期。
- Main 串行处理设置写入，拒绝过期草稿。先通过已有设置发布日志持久化，再向 Runtime 发布紧凑工具集合与修订号。Runtime 同步替换集合后发送工具变更通知并确认修订号。确认丢失不宣称成功；页面显示保存但未确认生效，允许显式重新应用，下次启动使用保存值。
- 设置主页面仅保留策略选择器和编辑入口。自定义编辑使用分类导航、搜索、逐项勾选、当前筛选全选及单一“保存并应用”。窄窗口分类改用下拉。系统策略可复制，复制/删除收于更多菜单，关闭脏草稿需明确放弃。

## 影响与验证

策略独立于现有授权、Browser 桥接开关、Computer 防护和监听重启设置，不改变 Agent core。测试覆盖持久化、无效/过期请求、受信 IPC、同会话发现与缓存调用拒绝、在途调用完成，以及真实 Electron 的新建、搜索、复制、删除、放弃与重启恢复。构建与实际视觉证据记录于 Executor 验证状态，发行与独立硬件验收保持各自门禁。
