# ADR-0087：录制事实归一化与工作流语义装配

- 状态：Accepted
- 日期：2026-10-30
- 范围：browser-extension 本地整理；用户已确认方案及实施

## 背景

整份工作流由模型重新生成动作、UUID 来源引用及顺序，再要求其严格逐项匹配录制，导致真实整理容易出现来源错配、遗漏与顺序错误。现有受控提供商主要验证工程链路，不能代替真实模型质量验收。嵌套控件名称丢失和跨批输入碎片进一步降低语义质量。

## 决策

1. 源端识别实际交互控件，增加文档内控件标识与编辑会话标识；不采集字段值，不将该标识作为重放定位器。
2. 原始记录不改写。整理时按版本化规则生成 RecordedAction，只有同文档、同控件、同编辑会话且连续的填写/选择片段可以合并，保留全部来源ID。普通点击、提交、按键保留。
3. 程序建立 DOM 子序列、明确因果与新标签页创建约束，使用本地捕获时间排名解决无约束节点排序，不向模型发送绝对时间或运行期身份。
4. 模型只输出动作短ID对应的意图、参数说明、读取建议和成功判据；动作类型、顺序、页面、事实来源、基础参数引用及确认门禁由程序组装。
5. 模型缺失语义标记为待审阅，不伪造事实；无效JSON、未知/重复动作引用等失败保留受限诊断。危险操作与来源校验仍适用。没有自动重试。
6. 保持既有最终Workflow schemaVersion=1；新增编译协议与归一化版本独立记录。旧工作流继续按其原证据校验；旧录制缺少身份时不猜测合并、不改写或自动迁移。

## 取舍

采用程序事实骨架和有界语义输出，增加少量纯规则代码，以减少模型负责的精确机械约束。暂不实现任意语义删步骤、根据label合并、全量DOM采集、第二套页面执行器或第三方Agent框架。

## 验证

规则与浏览器回归涵盖嵌套控件、中文输入、跨批编辑、同名不同控件、blur/暂停/导航边界、跨标签页因果、旧录制与错误模型响应。真实模型单独报告首次完整出稿率、语义质量和人工补充比例；预计10类脱敏流程各3次，执行前另行确认样本及调用费用范围。

## 真实模型验收后的修订（2026-10-30）

MrToken qwen3.6-flash-open 的30次合成调用得到25份有效草稿、3份旧目标待核对、2次结构校验失败。另行审阅发现成功条件存在无依据URL/选择器、含糊条件及同名参数问题；工程通过不等于语义验收通过。

语义协议版本1兼容可选 parameter:null，等同省略，仍拒绝空 successCriteria。归一化版本2把submit视为需要人工核对的提交观察，不映射为额外click；保留原事件和既有工作流，不自动迁移或重放。提示词补充明确成功条件与URL/选择器证据约束。上述修正发生于30次调用之后，仅离线验证，真实请求额度已用完，不声称新版本已获得同样实测结果。

## 成功条件发布边界补充

2026-10-30继续优化：补充仅由现有脱敏记录派生的验证上下文；草稿可保留待修改的成功条件，但客观不可执行的地址/元素目标不得发布，即使已勾选审批。合法的未观察条件仅作待核对建议。无效元素占位值与合法文字匹配区分。参数显示名用记录事实和顺序编号保持可辨识，不改变变量绑定。该边界不承诺自动验证真实业务完成。
