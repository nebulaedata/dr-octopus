# Server 设置设计审查与范围收敛

> 更新：2026-09-15。以当前[主设计](./settings-server.md)、[实施契约](./settings-server-contracts.md)和 [ADR-0053](../adr/0053-server-settings-gui.md)为准。本文记录已处理的设计问题，不表示实现测试通过。

## 当前范围

保留：对外监听开关、端口、工作区与全局会话实例上限、文件日志与轮转、用户手动重启服务。允许远程管理，与其他设置一致。

按用户最新要求删除出站代理配置及代理排除，其字段、隐藏/展示争议、复用操作、客户端适配和验收任务均不属于本模块。已完成的通用 Server 环境变量注入机制保留，本次不回滚代码、不删除用户文件配置。

## 审查问题处理

| 问题                                 | 收敛后的规则                                                                  |
| ------------------------------------ | ----------------------------------------------------------------------------- |
| 出站代理配置牵涉额外接口与客户端行为 | 已移出范围，不再作为本模块开发前置条件                                        |
| release 同源页面被来源白名单拒绝     | HTTP/SSE/WS 同源直接允许；额外 Origin 才查白名单；不把局域网同源请求当跨域    |
| 保存与运行值比较混淆                 | 持久化键的存在性与值决定 applied/unchanged；current/next 差异只决定待重启提示 |
| 保存是否自动重启                     | 永远不自动重启；用户点击并确认后执行，保存和重启为独立动作                    |
| 保存响应丢失                         | GET 核对当前文件目标键值；无法核对则结果未知，保留草稿、不自动重放            |
| 全局写入 lease 与自动中断判断过重    | 删除全应用 lease 和 allowInterrupt；用户确认可能中断会话后复用现有优雅关闭    |
| 保存与重启本身的竞争                 | 仅两个 Server 配置入口和重启接受共用短时串行队列，不扩展到所有业务模块        |
| 重复重启、停止与重启竞争             | 宿主持有有界幂等记录，stop 优先；保留必要的代际检查                           |
| 外部文件修改导致本次应用漂移         | 使用接受时冻结快照；后续外部修改留待下次应用                                  |
| 启动失败后不清楚实际运行配置         | 最多恢复旧运行快照一次，保留目标文件；区分 restored 与 succeeded              |
| Vite 端口变化                        | 明确开发配置与固定转发目标的手动同步路径，不作为 release 默认跨域设计         |

## 补充完整性检查

已按用户确认补充“网络访问 → 高级设置 → 允许的额外来源”列表，明确新增/删除、规范化、空列表与恢复继承、启动覆盖和移除当前来源的提示。

另补配置加载失败不以默认值覆盖、并发冲突保留草稿，以及重连后按 operation 状态区分成功与旧配置恢复。恢复结果增加 actualAddress，避免恢复后仍将目标新端口误作当前地址。这些是已有范围的交互与错误处理细化，不增加全局控制机制。

## 开发与验证边界

设计不再要求代理接入调查、任意业务写入追踪或自动判断所有任务能否安全中断。保留配置文件原子更新、显式危险确认、优雅关闭、资源释放后再启动以及可解释的失败状态。

实际实施仍需验证：字段/DTO 一致、两处配置入口冲突、重启重复请求、停止优先、关闭失败、启动失败恢复、远程同源 HTTP/SSE/WS、端口变更及日志轮转。验证结果按实际执行记录；文档检查不替代应用验收。
