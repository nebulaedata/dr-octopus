# 浏览器优先的 Skill 离线闭环

2026-11-02，用户同意默认浏览器保存、离线重放/导出、连接后显式保存到Executor，并要求设计后实施。本方案替代统一Agent方案中“必须落盘才完成整理”的规则。离线仅指Executor不可用，不代表无需模型服务或目标网站网络。

## 所有权与状态

Worker/IndexedDB保存技能快照、内容摘要、缓存时间、录制关联和会话结果。默认storage=browser。整理提交由单一事务同时写入快照/绑定、原tool result及completed状态；失败保持候选与旧绑定，重试不调用模型。每次重新整理使用新skillId，不覆盖磁盘手改文件。

可选storage=executor表示用户已明确保存到固定技能库且回执已确认。磁盘为该关联的最新来源；浏览器保留最后成功读取的副本。副本是已知版本，不宣称与当前磁盘一致。完整快照携带内容摘要，导出/重放前重新校验格式、摘要和允许站点。本次运行固定快照；后续变更不影响正在运行的会话。

现有已保存技能的数据库版本升级只补充storage和已有候选副本，不删除录制或模型配置、不恢复旧工作流兼容路径。没有可恢复候选时明确无缓存，须在线读取一次。已有尚未保存候选允许“重试保存”提交浏览器事务，无需重新整理。

## 保存到磁盘

仅显式命令触发，绑定当前recordingId/skillId，禁止任意路径。先落盘保存意图，再查询相同operationId回执；没有回执才create。operationId使用该不可变浏览器副本的skillId。回执与候选摘要匹配后事务更新storage=executor；原绑定已被新整理替换则拒绝覆盖新关联。掉线/超时保留意图和错误，下次同ID先查回执。重启不自动发起文件写入。自动重连只恢复连接，不推送或覆盖文件。

磁盘已关联时不提供覆盖写入，手工编辑只通过磁盘读取回流。重新整理必须新副本。写入失败、协议不匹配、权限失败不会撤销本地浏览器保存，也不会调用模型补偿。

## 重放来源选择

- browser：直接读取并校验浏览器快照，不调用Native，照常检查模型发送授权、站点权限和页面所有权。
- executor：读取当前磁盘稳定快照，校验范围并缓存，再开始本次运行。
- 只有明确离线或只读请求结果未知时，允许提示“本地文件不可用，是否使用浏览器副本”；确认绑定skillId和缓存内容摘要，创建重放会话与关联/摘要比较位于同一IndexedDB事务，缓存或关联变化则拒绝旧确认。
- 文件不存在、格式错误、路径/站点越界不自动回退，保留具体错误。缓存缺失或损坏也不能降级为成功。
- 用户拒绝缓存时不创建会话、不发送模型请求、不占用页面。使用缓存的会话记录来源与副本时间，不能伪称读取了磁盘最新版本。

## 导出与删除

导出固定两个文件SKILL.md/workflow.json的ZIP，内容仅来自所选浏览器副本，不附加模型配置/密钥、会话、录制原始数据或重放输入。文件名使用skillId，模型名称不参与路径。仅用户点击发起下载，提示“已发起下载”，不能宣称用户已保存文件；不新增downloads或任意目录权限。已关联磁盘时导出也明确是浏览器副本，可能落后于手改文件。

删除录制沿用现有确认，不删除已导出文件/磁盘技能。浏览器数据清理或卸载扩展会失去浏览器副本；导出和本地目录是可选持久备份。

## 局部交互

保持详情外框/导航/footer。技能状态注明保存在浏览器或已关联本地目录；原文件区复用Button/DropdownMenu提供导出副本、保存到本地目录和打开关联目录。未关联时不能误显示磁盘可打开。缓存确认复用Dialog，明确缓存时间与未包含后续手改的可能；当前业务会话展示简短来源提示。旧卡片视觉稿已弃用，不恢复。
