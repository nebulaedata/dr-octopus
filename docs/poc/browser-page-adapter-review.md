# 浏览器页面适配层限制审查

日期：2026-11-03。范围为扩展 PageControllerAdapter、BrowserRouter、Builtin Agent 工具准入与固定的 `@page-agent/page-controller@1.12.4`。目标是区分重复限制与上游没有承担的产品职责，不以代码行数减少或合成测试通过证明任意网站可执行。

## 依据与结论

实际检查固定包的公开类型与实现：PageController承担DOM提取、元素索引和点击/填写/选择；iframe访问失败会捕获异常、跳过内部内容。动作查找使用索引保存的真实元素引用，不替调用方校验扩展任务、窗口、浏览器documentId、录制语义或截图脱敏。因此“全部交给上游”和“所有现有检查都必要”都不成立。

| 检查 | 独立评估 | 本次处置 |
| --- | --- | --- |
| 跨域/不可读iframe导致整页拒绝 | 比上游严格，阻断无关主页面 | 前轮已移除；保留SOP与不可读取内容的说明 |
| 固定8层iframe上限 | 与是否可读取/可定位没有直接对应；已有总遍历预算 | 删除深度专属拦截；9层同源页面观察已测 |
| 快照期间标题变化即TARGET_CHANGED | 未读数、后台通知等元数据变化不证明文档或目标失效 | 删除标题相等条件；URL及文档身份检查保留 |
| 根列表必须顺序和长度完全一致 | 无关新frame/shadow root或遍历顺序变化，并不改变既有索引引用 | 改为根身份集合比较；无选择约束的普通动作允许新增根，仍拒绝已观察根消失、文档替换或URL变化 |
| 普通快照的beforeUpdate重复遍历所有根 | 无选择要求时没有需要修改的选择索引 | 无choiceTarget/choices时直接使用上游默认索引，避免重复全页遍历 |
| 遍历可访问根本身 | 仍供敏感内容处理、录制选择定位、文档身份检查使用 | 保留并命名为collectAccessibleRoots，不能把隐私/身份职责一起删掉 |
| 截图/选择要求必须覆盖完整根集合 | 新增根可能有未脱敏内容，或出现同名选择导致歧义 | 保留完整覆盖检查，不沿用普通动作的宽松条件 |
| 页面/任务/连接/窗口/控制器/快照身份 | 上游不持有这些扩展授权及生命周期事实 | 保留，禁止把旧索引映射到新文档 |
| 站点范围和浏览器权限 | 产品授权职责，不是DOM提取限制 | 保留；不得由模型或网页内容扩大 |
| 每轮一个副作用、未知结果不重发 | 防止问答前派发或重复业务动作 | 保留；应区分派发前拒绝与真正未知，不统一放开 |
| 128根、100,000元素及快照分页/字节限制 | 遍历与传输预算，避免处理不完整却宣称完整脱敏 | 保留；不是声称上游不支持复杂页面，后续调整需资源证据 |
| 有不可访问frame即拒绝截图 | 无法检查内部敏感内容；DOM观察可继续 | 当前保留。未来可验证整块frame遮蔽，而非无条件开放截图 |

## 仍偏保守、不能直接删除的候选

1. **未满足任一录制选择就禁止所有普通点击。** 会挡住展开折叠区、打开选择弹窗等前置操作；但完全删除会回到“跳过必要选择直接提交”。需要有限的前置操作/提交约束证据，再缩小拦截范围；本次未改。
2. **打开后必须load complete。** 合法页面可能因无关第三方资源迟迟不complete；这比“主文档和受信接收器已就绪”更严格。初次审查未改；2026-11-03后续通过14秒慢资源夹具在旧侧载构建复现两浏览器outcome_unknown，已改为主文档与受信接收器就绪，并保留已创建tab的回执。前后证据见[验证记录](executor-validation.md)“打开主文档就绪与已知回执修正”。
3. **全局根失效仍比具体目标失效保守。** 已观察的无关frame消失仍会让主页面动作重新观察。若没有上游公开的目标所属文档信息，不能读取私有selectorMap或靠解析显示文本授权目标；本次仅放宽安全的新增/重排情况。
4. **固定60秒快照有效期。** 可能增加慢模型/长问答中的观察次数；但上游不承担跨请求的快照协议期限。先统计误过期，再决定是否调节，不因当前不便删除期限。
5. **某些派发前错误被归类为结果未知。** 应逐项验证错误实际产生阶段，尤其TAB_NOT_EXECUTABLE等前置拒绝。不可把所有异常一概视为未执行；本次未扩展错误分类改动。

上述是评估候选，不表示每一项已被实测为用户Gmail失败的原因，也不标记为本轮已修复。

## 验证与边界

- 真实固定PageController + Chrome/Edge隔离页面：标题在状态提取结束时变化、增加同源根后使用原主页面引用、9层同源嵌套、文档替换旧引用拒绝、跨域不读取及截图拒绝、合成表单一次提交，通过。
- 选择适配回归保持精确目标及原始点击保护，通过。以上两组共4/4，使用真实Controller，不修改上游源码、不操作真实邮箱、不调用付费模型。
- 证据归本地 `adapter-review/20261103-refine`；最终构建、静态检查和集成状态继续记录在 [Executor验证记录](executor-validation.md)。早期动态frame测试以新增根必须拒绝为断言，本轮将其更新为主页面目标可继续，保留文档替换拒绝断言；原先失败/修复证据不覆盖。
- 这份审查不是实际Gmail完整发送验收，不据此宣称所有重放错误均已解决。
