# Browser Host 生命周期验证计划

决策：[ADR-0090](../adr/0090-browser-host-lifecycle.md)。

2026-11-03 从 ADR-0090 迁入 2026-11-02 的验收计划，并按用户确认的新协议单线实施要求修订。以下均为计划，尚未执行；没有新增运行时通过证据。

以下为发行阻断验收，使用隔离 Windows 用户/Profile/测试 Host，保留真实打包产物证据。单元测试不能替代浏览器真实启动 Native Host。

| 场景                                                | 必须结果                                             |
| --------------------------------------------------- | ---------------------------------------------------- |
| 新用户安装，Chrome/Edge 首次连接                    | 无手工命令，真实 nonce 往返，权限仍需原有显式启用    |
| 正式版与 dev 同时运行、反复启动/停止/重建           | 注册、数据、Profile、连接互不影响                    |
| 更新后删除旧下载/安装目录，清理 dev dist            | 当前入口和 Host 仍可用                               |
| 新协议下扩展与 Executor 分别升级、协议不一致        | 同协议自动连接；不一致指出具体更新目标，无旧协议降级 |
| 写文件/写第一项注册/发布后进程崩溃、断电模拟        | 下次恢复为一致状态，有明确 journal，无混合组件       |
| 第二个浏览器注册失败、磁盘不足、文件被占用          | 分项结果准确，旧可用状态保留或恢复，不冒称全部成功   |
| 多个更新进程、旧进程启动、旧卸载器运行              | 只有当前所有者推进 generation，不倒退抢占            |
| 删除已知自有注册或破坏受管包                        | 自动恢复并重新验证                                   |
| 未知注册与旧 manifest 消失                          | 无盲目覆盖，确认修复后可恢复且保留备份               |
| Host/Runtime 崩溃、Worker 回收、浏览器重启/休眠恢复 | 有界恢复，真实状态一致，用户暂停保持                 |
| 点击/输入发送后断线、旧回复迟到                     | 不重放副作用，不污染新连接，未知结果保留             |
| 浏览器关闭、禁用扩展、撤销网站权限、策略禁止 Host   | 正确分层，不误判成功、不无限修复注册                 |
| 新包失败，旧包可用/已不兼容分别测试                 | 前者回退，后者明确待修复；不回滚用户数据             |

暂定验收目标：Executor 与已启用扩展均可运行时，正常安装/升级无需修复按钮；短暂进程故障在一次不超过 60 秒的恢复窗口内完成重连，计时排除浏览器关闭/休眠，实际 alarm 调度偏差单独记录。单次本地修复有 60 秒截止，超时必须收束并报告，不能挂起界面。目标需实测，当前不视为已达成。

## 并行开发边界回归

- 连接模块抽取前后，已有桥接与 popup 测试保持通过。
- 录制与本地技能在 Executor 离线时继续可用，模型和 Agent 业务不依赖新维护服务。
- SkillFileClient 断线清理、重连新会话、迟到回包和旧 post 拒绝均有覆盖。
- 两个 worktree 与正式实例并行，注册、端口、构建产物、Profile 和业务数据不交叉。
- 集成从同一提交构建两端，验证真实 Native Host 往返和动作断线不重放。
