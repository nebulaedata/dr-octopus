- 真实浏览器首次发送收到“测试完成”；发送前后使用同一 PID **26460**，同一 JSONL 路径。浏览器测试会话及文件已清理，目录恢复原有 4 条。

- 导入钩子验证公共 Agent 入口和静默安装不加载项目终端 UI。
- 桌面与 390 × 844 窄屏检查通过：输入、模型菜单、四项工具栏单行布局及跨断点草稿保留。浏览器控制台无新增错误。
- `pnpm test`、`pnpm lint`、`pnpm typecheck`，并额外执行 Web 的 `tsc -b`。复核期间曾有两个现有 RPC manager 测试触发 2 秒 readiness 超时；隔离复跑及随后完整测试通过，未放宽超时或修改测试断言。

### 已撤回的编译缓存实验（历史记录）

使用修改后的 CLI、全部已安装扩展、1024 MiB old-space；顺序交错运行，只发送 `get_state`，不调用模型。比较独立临时缓存目录，未使用先前诊断的 preload 探针。结果是本机小样本，不代表稳定性能承诺。

| 场景               | 启动时间                                  |
| ------------------ | ----------------------------------------- |
| 关闭编译缓存，3 次 | 6.397 / 5.793 / 5.401 秒，中位数 5.793 秒 |
| 首次建立缓存       | 11.211 秒                                 |
| 复用已有缓存，2 次 | 5.798 / 5.677 秒，均值 5.738 秒           |

本机没有观察到缓存带来明显、稳定的端到端提速，首次写入反而更慢。因此已按用户要求撤回该功能。当前优化来自将进程启动提前到首页，以及发送时复用该进程。有限并行留待后续单独设计。
