## 验证

回归包含真实 ExcelJS 工作簿、跨块中文/表情、DOCX 表格及脚注、PPT 顺序/备注、共享字符串随机访问、日期系统、嵌套 ZIP、CRC 损坏、路径穿越、累计解压限额、超长 XML 标记、取消与提前结束清理。

独立 Node 子进程在 `--max-old-space-size=64` 下验证约 42 MB DOCX XML（70,000 段）和约 48 MB XLSX 共享字符串 XML；测试按段消费，检查结果和临时文件清理。64 MiB 是 V8 堆上限，不是 RSS 总内存承诺。资源上限仍会拒绝极端输入，不承诺任意大小文件。

附件端到端验证包含真实文件类型检测、能力准入、处理子进程、文档产物和检索分块来源。知识库验证逐段确认、消费失败与取消、Lance 分批写入、幂等重试以及未发布修订的查询隔离。
