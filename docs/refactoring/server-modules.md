# Server 模块重构记录

## 范围与基线

仅修改 Server、其测试和相关规范，不修改前端、packages、schema 或迁移 SQL。共享业务能力具名发布，路由和请求 hooks 使用独立作用域；文件行数不是验收条件。

基线版本：`7b4b8a5659844c732336db53e0b2291f82877a9c`。重构前 build、lint、typecheck 通过；完整测试 375 项，374 通过、1 跳过、0 失败。测试覆盖会话发布、通知原子性、附件处理与备份、配置、HTTP、WebSocket、MCP 等现有契约。

## 最终验证

- `pnpm --filter @octopus/server build`：通过；先清理明确的编译输出目录，已删除的旧入口不会留在产物中。
- `pnpm --filter @octopus/server test`：380 项，379 通过、0 失败、1 项原有私有扫描 PDF 用例因未提供私有夹具而跳过。
- `pnpm --filter @octopus/server lint`、`typecheck`：通过；嵌套三目由 ESLint 检查，不设置文件行数限制。
- TypeScript 源码模式：使用 `node --import tsx` 启动真实应用，在隔离配置及内存数据库下验证 `/api/health`、`/api/ready`、`/api/capabilities` 及错误前缀路径，关闭成功。
- 模块检查：全部入口和角色文件合规，公共跨模块导入无环，service 不依赖完整 Fastify 实例，业务模块不初始化 SQLite 连接。
- 基线对照：从基线 Git 版本提取路由声明和原始 SQL，经 TypeScript AST 对照保持一致；schema 的规范化文本哈希未变化。静态对照不替代运行时业务回归。
- `test:e2e:sse`：相同测试分别运行于基线 Server 和重构后 Server，两者均通过。跨页面更新、通知读回执、调度变更与断线重连满足原断言；空闲业务查询增量为 0，重连后活动流数量为 1。

## 测试适配与故障排查

- 资源工厂和模块路径变化同步更新测试装配，保持业务断言；干净构建发现并修正了两处子进程脚本中的旧路径。
- 浏览器用例在基线 Server 上同样失败：运行时替身缺少已有 `getControl()` 契约，导致会话列表返回 500；部分 ARIA 定位仍使用旧中文名称。仅补齐测试替身、采用未修改前端已有的英语 ARIA 名称，再将同一套测试应用于两个版本，未修改页面或放宽业务断言。
- Vite 冷依赖优化曾触发首次导航超时，预热后完成浏览器验证；知识守护服务出现过一次启动超时，隔离重跑和完整回归均通过，未增加超时或跳过检查。
- `apps/web`、`packages/`、`src/db/schema.ts` 和 `drizzle/` 无工作区改动；没有引入新旧双注册、兼容层、协议升级或数据库迁移。

架构依据见 [ADR-0066](../adr/0066-server-module-autoload.md)，替代 ADR-0018 的完整 Fastify Service 上下文约定。

## 不变量

- 每模块只有一条注册路径，SQL、事务、默认值、错误及协议行为保持不变。
- 业务漂移阻止后续阶段；不修改行为断言迁就新实现。
- 会话与通知、草稿、首次发送接受、附件引用与回收的原子边界保持完整。
